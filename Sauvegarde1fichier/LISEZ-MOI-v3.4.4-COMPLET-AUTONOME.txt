SAUVEGARDE 1FICHIER ★ BLONDIN EDITION ★ v3.4.4
INSTALLATEUR COMPLET ET AUTONOME — BATOCERA 44
21 novembre 2026

OBJECTIF
Installer Sauvegarde 1fichier sur un Batocera 44 vierge sans installer les anciennes versions.
Cet installateur fournit dans UN SEUL FICHIER :
- moteur Batocera / raccourci Ports / visuels
- interface mobile (port 8765) et authentification
- évolution media.zip et vérification manuelle sans retransfert
- catégories Consoles, Ordinateurs et Arcade sur 1fichier
- inventaire cloud v3.3 et présentation Web v3.4.4
- défilement stable et sélections indépendantes entre Sauvegarder / Vérification

DEPENDANCES
- Batocera 44, exécution sous root, python3, bash et flock
- L'extinction automatique V3 est FACULTATIVE sur Batocera vierge.
  Si elle est déjà installée, ses protections préexistantes restent utilisées.
  Si un seul script de veille existe sur les deux attendus, l'installateur
  refuse par sécurité plutôt que de modifier un service incomplet.
- Le compte Rclone/1fichier pourra être configuré après la première installation.

INSTALLATION DEPUIS GITHUB
curl -fLsS https://raw.githubusercontent.com/blondin-svg/blondin.rep/main/Sauvegarde1fichier/install-v3.4.4-COMPLET-AUTONOME.sh -o /tmp/install-v3.4.4-COMPLET-AUTONOME.sh && bash -n /tmp/install-v3.4.4-COMPLET-AUTONOME.sh && bash /tmp/install-v3.4.4-COMPLET-AUTONOME.sh

CONSERVER L'INSTALLATEUR POUR REINSTALLER SANS INTERNET
mkdir -p /userdata/saves/Installscripts
curl -fLsS https://raw.githubusercontent.com/blondin-svg/blondin.rep/main/Sauvegarde1fichier/install-v3.4.4-COMPLET-AUTONOME.sh -o /userdata/saves/Installscripts/install-v3.4.4-COMPLET-AUTONOME.sh
bash -n /userdata/saves/Installscripts/install-v3.4.4-COMPLET-AUTONOME.sh

INSTALLATION HORS LIGNE (fichier local déjà copié)
bash /userdata/saves/Installscripts/install-v3.4.4-COMPLET-AUTONOME.sh

COMPORTEMENT SUR INSTALLATION EXISTANTE
- Les fichiers moteur/Web évolués sont remplacés par les versions embarquées,
  avec des sauvegardes automatiques prévues par les modules.
- Le contenu des sauvegardes et les dossiers locaux/distants ne sont pas transférés,
  supprimés ni réorganisés par l'installateur.
- dossiers.json, authentification Web et configuration Rclone sont destinés à être conservés.
- Une sauvegarde personnelle des paramètres reste recommandée avant une réinstallation.
- Ne pas lancer pendant une sauvegarde, vérification ou renvoi media.zip.

INSTALLATION TERMINÉE
- L'installateur demande un redémarrage complet à la fin ; la session SSH se coupe.
- Revenir sur http://IP_DU_BATOCERA:8765 puis rafraîchir le navigateur Android.
- Le mot de passe Web est affiché lors de la première installation ; le noter.
- Ne jamais exposer le port 8765 directement sur Internet ; utiliser un VPN.

TESTS ET LIMITES
- Ensemble assemblé à partir des sources GitHub des versions v3.1, v3.3, v3.4.3 et v3.4.4.
- Contrôles structurels des sources intégrées et de leurs points d'injection.
- Fonctionnement sur une machine Batocera 44 neuve et sur une installation existante
  À CONFIRMER PAR TEST RÉEL : aucune exécution complète sur Batocera n'a été effectuée ici.
- En cas d'erreur, ne pas relancer immédiatement ; conserver la sortie du terminal
  pour identifier l'étape avant tout nouvel essai.
