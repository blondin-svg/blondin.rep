SAUVEGARDE 1FICHIER ★ BLONDIN EDITION ★ — v3.1-COMPLET
Batocera 44 — interface Batocera + Web mobile
17 novembre 2026

OBJECTIF DE LA VERSION
Réorganiser l'interface Web devenue trop longue, tout en conservant le moteur de
sauvegarde et les fonctions media.zip de la v3.0.

NOUVEAUTÉS WEB
- Navigation mobile compacte en six rubriques : Accueil, Sauvegarder,
  Historique, Vérification, Compte 1fichier / Rclone, Réglages et outils.
- Accueil avec le NOM du dernier système sauvegardé, sa date et l'état du bilan.
- Affichage direct des cinq systèmes sauvegardés les plus récemment.
- Historique des systèmes récents avec recherche par nom et détail des opérations.
- Mise en correspondance des contrôles manuels postérieurs au transfert :
  ✓ contrôlé/validé ; ◷ transféré sans vérification ; ✗ échec de contrôle ou transfert.
- Fenêtre de progression toujours accessible depuis Accueil.
- Actualisation automatique de l'état toutes les 2,5 secondes, conservée.
- Récupération jusqu'aux 300 derniers événements de l'historique déjà conservé
  par le moteur. Les événements anciens supprimés par la rotation ne peuvent pas
  être reconstitués.
- Les écrans du compte, de media.zip, des journaux et de l'extinction sont
  toujours présents, désormais dans des rubriques distinctes.

FONCTIONS CONSERVÉES
- Moteur d'envoi vers 1fichier.com et Rclone.
- Exclusions images, manuals, videos et media ; création de media.zip.
- Renvoi de media.zip après échec, sans recopier les jeux.
- Contrôles manuels indépendants, annulation, journalisation.
- Sécurité du verrou transfert, protection extinction, authentification Web.
- Configurations existantes, clé API, mot de passe, historique et ntfy.

INSTALLATION DEPUIS GITHUB (SSH root sur Batocera 44)
Exécuter cette commande EN UNE SEULE LIGNE, sans l'opérateur « | bash » :
curl -fLsS --retry 3 https://raw.githubusercontent.com/blondin-svg/blondin.rep/main/Sauvegarde1fichier/1fichier-blondin-v3.1-COMPLET.sh -o /tmp/1fichier-blondin-v3.1-COMPLET.sh && bash /tmp/1fichier-blondin-v3.1-COMPLET.sh

FICHIER GITHUB
https://github.com/blondin-svg/blondin.rep/blob/main/Sauvegarde1fichier/1fichier-blondin-v3.1-COMPLET.sh

PRÉCAUTIONS
- Ne lancer aucune sauvegarde, vérification ou opération media.zip durant
  l'installation. L'installateur vérifie les opérations avant toute modification.
- La protection d'extinction automatique V3 doit déjà exister.
- Le programme conserve les données et fait des sauvegardes des composants
  remplacés dans /userdata/system/1fichier-blondin/backups/.
- La version COMPLETE peut redémarrer Batocera après une installation réussie.
  La connexion SSH peut alors se couper.
- Interface Web : http://IP_DE_BATOCERA:8765
- Ne jamais exposer ce port HTTP sur Internet. Utiliser le VPN WireGuard.
- Les tests techniques et de navigation ne remplacent pas une validation
  en conditions réelles sur Mini-PC / Batocera 44.

VERSION HISTORIQUE
La v3.0-COMPLET reste sur GitHub sans changement.
