INSTALLATION DEPUIS GITHUB (v3.4.3 déjà installée)
curl -fLsS https://raw.githubusercontent.com/blondin-svg/blondin.rep/main/Sauvegarde1fichier/install-v3.4.4.sh -o /tmp/install-v3.4.4.sh && bash /tmp/install-v3.4.4.sh

INSTALLATION HORS LIGNE
Copier install-v3.4.4.sh dans /userdata/saves/Installscripts puis :
bash /userdata/saves/Installscripts/install-v3.4.4.sh

CONTROLE SANS MODIFIER LES FICHIERS
bash /userdata/saves/Installscripts/install-v3.4.4.sh --check

SECURITE
- L'installateur nécessite les marqueurs Web de la v3.4.3.
- En cas de structure Web inattendue : arrêt sans modification.
- Sauvegarde automatique de mobile/app.js et mobile/index.html avant remplacement dans
  /userdata/system/1fichier-blondin/backups/avant-web-v3.4.4-...
- Reinstallation sans doublon (idempotente).
- Refus d'installation si l'état local signale une sauvegarde/vérification active.
- Aucune modification des archives locales/distantes, des comptes Rclone ni des destinations 1fichier.
