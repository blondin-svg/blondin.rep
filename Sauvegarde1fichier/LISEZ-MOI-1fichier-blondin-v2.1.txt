INSTALLATION / MISE A JOUR
1) L extinction V3 doit etre deja installee. Aucune sauvegarde/verif ne doit etre active.
2) Copier 1fichier-blondin-v2.1.sh dans /userdata/saves/Installscripts.
3) Lancer en SSH root :

   bash '/userdata/saves/Installscripts/1fichier-blondin-v2.1.sh'

4) Apres succes, le Mini-PC redemarre automatiquement. SSH sera temporairement coupe.
5) Version mobile : http://IP_DU_BATOCERA:8765 ; depuis l exterieur, VPN WireGuard Freebox.

IMPORTANT
- Ne pas exposer le port 8765 directement sur Internet.
- Aucune sauvegarde ni verification 1fichier n est lancee pendant l installation.
- La rotation automatique depend du service Web mobile demarre (premier essai environ 60 s apres demarrage, puis toutes les heures si besoin; nettoyage au plus une fois par jour).
- Les rapports de verification sont conserves 90 jours ; certains journaux sans bilan clair sont conserves prudemment plus longtemps en cas d erreur.
- Les anciennes copies de programme dans /userdata/system/1fichier-blondin/backups ne sont PAS effacees.
- Tous les fichiers sont embarques ; aucun telechargement Internet requis pour installer.
- Les essais effectues en environnement de simulation ne remplacent pas une validation sur ton Mini-PC.
