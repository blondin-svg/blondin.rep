Batocera 44 — 21 novembre 2026

NOUVEAUTÉ : RECONNAISSANCE DES ARCHIVES EXISTANTES
Analyse en lecture seule de 1fichier:Sauvegarde Batocera/
  Consoles/<système>
  Ordinateurs/<système>
  Arcade/<système>

L'outil retrouve les dossiers, compte les fichiers et les octets, et conserve
une date de modification distante lorsqu'elle est disponible. Il enregistre
une date de détection distincte. La présence d'une archive ne signifie pas
qu'elle est vérifiée.

Si une nouvelle installation de Batocera ne possède plus les anciennes
configurations locales, l'outil peut reconstruire les associations connues
(PlayStation 2, Switch, Windows, Lindbergh, TeknoParrot, Namco System 3xx)
lorsque les dossiers ROM locaux existent et correspondent aux catégories.
Les autres systèmes sont inventoriés sans inventer de chemin local.

AUCUN transfert, déplacement, remplacement ou effacement sur 1fichier.
L'historique local existant conserve la priorité et le résultat de détection
est identifié DETECTEE / A VERIFIER. Le contrôle manuel est indépendant.

LANCEMENT
Dans Batocera : Contrôles et journaux > Synchroniser les archives 1fichier
Ou SSH :
  python3 /userdata/system/1fichier-blondin/cloud_sync_v33.py --recover

INSTALLATION COMPLÈTE DEPUIS GITHUB (SSH root, Batocera 44)
  curl -fLsS https://raw.githubusercontent.com/blondin-svg/blondin.rep/main/Sauvegarde1fichier/install-v3.3.sh -o /tmp/install-v3.3.sh && bash /tmp/install-v3.3.sh

Cette commande réutilise le socle v3.2 fixé et installe la synchronisation
v3.3 avant le redémarrage éventuel. Elle ne lance pas de scan ni de transfert
automatique pendant l'installation.

MISE À JOUR LOCALE SANS INTERNET POUR L'INSTALLATION
Si la v3.2 est déjà installée, utiliser maj-locale-v3.3.sh (fourni comme
fichier distinct) dans /userdata/saves/Installscripts/, puis :
  bash /userdata/saves/Installscripts/maj-locale-v3.3.sh
Redémarrer ensuite Batocera. L'inventaire réel requiert une connexion 1fichier.

WEB
L'interface Web continue de présenter les statuts habituels et inclut
un panneau d'informations pour les archives détectées dans l'historique.
Le lancement d'un nouveau scan se fait depuis Batocera ou SSH ;
aucune nouvelle API Web sans authentification n'est ouverte.

SÉCURITÉ ET LIMITES
- Refus de synchroniser pendant une autre opération.
- Copie locale des fichiers applicatifs avant mise à jour.
- En cas d'erreur réseau, pas de faux bilan d'absence.
- Une coche verte exige toujours un contrôle manuel confirmé.
- Les dates distantes peuvent ne pas refléter la date de sauvegarde initiale.
- Tests de compilation/simulation effectués ; vérification physique
  sous Batocera 44 et compte 1fichier réel encore nécessaire.
